# Gourav Raj Jajware — Portfolio

Responsive, single-page portfolio built with HTML and CSS. No build tools are required.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `gouravrajjajware066-hash.github.io`.
2. Upload `index.html` from this folder to the repository root and commit.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Once published, your site should be available at `https://gouravrajjajware066-hash.github.io/`.

## Before publishing
